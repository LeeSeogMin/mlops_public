# LMS 과제 채점 (제출·첨부 유무 기준)

2026-10-22에 1강을 채점하며 정한 방식이다. 수강생 18명, 과제당 만점 2점.

## 1. 채점 기준

| 상태 | 점수 |
|---|---|
| 미제출 | 0점 |
| 제출했고 첨부파일이 있음(본문 유무와 무관하게 파일이 하나라도 있으면 인정) | 2점 |
| 제출했으나 첨부파일 없이 본문에 링크만 씀 | 0점 (1강에서 사용자가 정한 결정. 박채원·전영준) |

- 과제 안내문(`lecture/chNN.md`의 「과제」절)은 산출물 여러 개와 서술 답안을 요구하지만, 이 기준은 내용 품질을 보지 않는다. 파일이 하나라도 올라왔는지만 본다.
- 링크 제출자는 처음에 "링크가 열리면(HTTP 200) 인정"으로 정했다가 사용자가 0점으로 바꿨다. 링크 제출자를 2~7강에도 0점으로 적용할지는 사용자가 아직 확정하지 않았다. 해당 학생이 나오면 먼저 묻는다.
- 중간고사 과제(만점 25)는 이 기준의 대상이 아니다.

## 2. 사전 합의 (매번 확인)

- 채점 기준과 저장까지 입력할지를 사용자에게 확인한다. 점수 저장은 학생 성적에 반영되는 작업이다.
- 1강처럼 한 과제를 먼저 저장하고 결과를 확인한 뒤 다음 과제로 넘어간다.

## 3. 절차 (Chrome 확장 도구 사용)

1. LMS는 주소로 직접 들어가면 메인 화면으로 돌려보낸다. 아래 순서로 메뉴를 눌러서 들어간다.
   - 메인 상단 「나의 강의실」 → 「AI데이터개발과MLOps(A반)」 카드 → 왼쪽 메뉴 「과제출제/채점」
   - 강의실에 들어간 상태에서만 `/lms/class/report/prof/doListView.dunet`가 열린다.
2. 과제 목록 표에서 해당 강의 행의 파란 「채점하기」 버튼을 누른다. (`find`가 준 ref로 누르면 안 열리는 경우가 있어 좌표로 누른다.)
3. 채점 화면의 표에서 제출여부(제출/미제출)를 읽는다. `get_page_text`로 18명 전체가 나온다.
4. 제출자의 첨부 유무는 행 끝의 「보기」를 눌러 모달(제출과제 내용보기)에서 확인한다.
   - 모달 안의 「다음>」으로 이름순으로 넘어간다. 한 번 누르고 3초 기다린 뒤 캡처한다. 곧바로 캡처하면 빈 모달이 찍힌다.
   - 모달 내용은 `get_page_text`에 나오지 않는다. 캡처(`scale 0.6`이면 읽힌다)로 읽는다.
   - 「첨부파일」 칸이 비어 있으면 첨부 없음이다. 닫을 때는 모달 아래 「닫기」(좌표 약 1123,680)를 누른다. 닫은 직후 첫 클릭은 무시되는 경우가 있어 모달이 열렸는지 캡처로 확인한다.
5. 점수 입력은 `read_page`(interactive)나 `find`로 각 행의 「취득점수 입력」 ref를 얻어 `form_input`으로 넣는다. 한 화면에 15행까지만 ref가 잡히므로, 16~18행은 `find`로 따로 구한다.
6. 입력이 끝나면 표 아래 「저장하기」를 누른다.

## 4. 저장 후 확인

- 저장 직후 페이지가 수십 초 응답하지 않는 일이 1강에서 두 번 있었다. 캡처와 `javascript_tool`이 모두 타임아웃으로 실패한다. 재시도를 반복하지 말고 사용자에게 Chrome 창에서 새로고침(F5)해 달라고 요청한다.
- 새로고침 뒤 「최종점수」 칸에 값이 채워졌는지, 과제 목록의 「채점 현황」이 (제출자 수)가 아니라 (채점한 인원)/18로 바뀌었는지 읽어서 확인한다. 1강은 사용자가 채점 현황에서 반영을 확인했다.
- 한 번 더 저장해 점수를 고칠 수 있다(박채원·전영준을 2점에서 0점으로 바꾼 예).

## 5. 주의

- `javascript_tool`로 DOM을 읽으려 하면 쿠키·쿼리 문자열 차단 메시지가 나올 수 있다. 화면 캡처와 `form_input`을 쓴다.
- 「2차 추가」 버튼과 2차 과제 점수는 건드리지 않는다. 화면 안내에 따르면 2차 점수를 주면 1차 점수가 삭제된다.
- 「SMS발송」「쪽지발송」「제출파일일괄다운로드」 등은 사용자 요청 없이 누르지 않는다.
- 값을 지어내지 않는다. 확인하지 못한 학생의 점수는 입력하지 않고 보고한다.
